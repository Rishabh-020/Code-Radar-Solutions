## 🚀 Getting Started

### Prerequisites
- GCC compiler (or any C compiler)
- Basic understanding of C programming

### Compiling and Running

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Rishabh-020/Code-Radar-Solutions.git
   cd Code-Radar-Solutions
   ```

2. **Navigate to a problem directory:**
   ```bash
   cd "Check if a String is Binary@@67877c59ddaeab38c8ad25b6"
   ```

3. **Compile the code:**
   ```bash
   gcc code.c -o solution
   ```

4. **Run the executable:**
   ```bash
   ./solution
   ```

### Example Usage

```bash
# Compile and run a string problem
cd "Check if Two Strings are Anagrams@@676c039d80e1714600f6764a"
gcc code.c -o anagram_check
./anagram_check
# Enter your test inputs when prompted
```
